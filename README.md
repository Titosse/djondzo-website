# Djondzo Website

Website público e institucional do Djondzo Escolar.

## Objetivo

- Apresentar o Djondzo a escolas e instituições de ensino.
- Captar pedidos de demonstração.
- Construir presença orgânica no Google e em mecanismos de pesquisa baseados em IA.
- Manter o painel do sistema separado do website público.

## Stack

- Next.js
- App Router
- TypeScript
- Tailwind CSS
- Lucide React

## Desenvolvimento

```bash
npm install
npm run dev
```

Abra:

```text
http://localhost:3000
```

## Produção

Por padrão, a configuração considera:

```text
https://djondzo.co.mz
```

Antes do deploy, confirme:

- domínio;
- e-mail comercial;
- número de WhatsApp;
- screenshots reais;
- logótipo final;
- preço comercial;
- URL real do painel.
