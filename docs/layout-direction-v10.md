# Djondzo Website — Layout Direction v10

## Objectivo

A v10 mantém a narrativa e os previews reais da v9, mas reduz a sensação de conteúdo colado às laterais.

## Larguras

- `.container-djondzo`: 1120 px máx.
- `.container-djondzo-wide`: 1160 px máx. (Hero)
- `.container-djondzo-reading`: 900 px máx.
- `home-product-stage`: 700 px máx.
- `home-tour-stage`: 1040 px máx.
- `showcase-frame`: 760 px máx.

## Gutter responsivo

- Mobile: ~12 px por lado.
- Tablet/desktop pequeno: ~24 px por lado.
- Desktop largo: ~48 px por lado no mínimo, aumentando automaticamente quando a viewport é maior que o container.

## Regra visual

Os fundos de secção podem ocupar toda a largura para marcar mudança de contexto, mas o conteúdo nunca deve esticar-se apenas porque há espaço disponível.

O visitante deve perceber um eixo vertical consistente ao percorrer:
Hero → fluxo escolar → produto → académico → financeiro → Mediateca → aluno → módulos → preço → FAQ → conteúdo → demonstração.

## Produto

Os previews do Djondzo continuam a partir do frontend real e permanecem suficientemente grandes para mostrar o produto, mas deixam de dominar toda a largura útil da página.
