# UI/UX research notes — v6

## Impeccable principles applied
- Remove AI-slop patterns: nested cards, identical feature grids, excessive glow/shadow, huge generic hero text and redundant labels.
- Layout before polish: reading order, grouping, density and responsive reflow are treated before decoration.
- Typesetting as a system: limited type roles, readable line length and consistent weights.
- Distill: remove repeated section labels and meaningless numeric ornaments.
- Harden: avoid fake metrics, support long text, keep controls accessible and preserve mobile usability.
- Colorize: brand blue has a job (action/selection), while red/amber/green remain semantic states.

## Skill findings applied selectively
UI UX Pro Max returned a playful education/Claymorphism direction for a broad education query. That direction was rejected because Djondzo is administrative B2B software for schools, not a children's learning app. A narrower search returned Minimalism & Swiss Style for professional administrative software, which fits the product better.

The skill also suggested:
- Professional blue/slate palettes
- Lexend + Source Sans 3 for accessible corporate trust
- Modular typography
- Visible keyboard focus
- Mobile-first layout
- Testing at 320/375/414/768/1024/1440 widths

## Design-engineering skill findings
- No transition: all
- Use transform/opacity for motion
- Keep routine interaction motion short
- Use strong ease-out curves
- Add subtle press feedback
- Respect reduced motion
